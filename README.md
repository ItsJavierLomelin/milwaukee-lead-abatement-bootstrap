# Milwaukee Lead Abatement Pros (Bootstrap)

Bootstrap build of Milwaukee Lead Abatement Pros, written from scratch on the Cleveland/Detroit/Philadelphia Bootstrap template.

- Edit the phone number in `config/site.mjs`, then run `npm run build`.
- Page templates live in `source/pages.json` (route -> full HTML).
- Open `index.html` directly or `npm start` for a local server.
- Live preview: https://itsjavierlomelin.github.io/milwaukee-lead-abatement-bootstrap/
